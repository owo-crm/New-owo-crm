# 08 — Безопасность и RODO

Мы храним персональные данные клиентов чужих фирм. Мы — **процессор данных (podmiot przetwarzający)**, фирма-клиент — **администратор**.

## Обязательно до первого платящего клиента

- [ ] RLS на всех таблицах + автотест «фирма A не видит фирму B».
- [ ] `service_role` ключ только на сервере; ни один клиентский бандл его не содержит (проверка в CI: grep по `.next/static`).
- [ ] Storage: приватные бакеты, путь `org/<organization_id>/...`, доступ только через signed URL (срок 10 мин).
- [ ] Публичная оферта `/o/[token]`: токен 32+ символа, случайный; без индексации (`noindex`); можно отозвать.
- [ ] Регион данных — ЕС (Supabase Frankfurt, Cloud Run europe-west1, Resend EU).
- [ ] Бэкапы: Supabase Pro (ежедневные + PITR).
- [ ] В логах нет телефонов, e-mail и текста сообщений (маскирование).
- [ ] Rate limit на логин, intake, публичные оферты.
- [ ] Пароли — Supabase Auth; минимум 10 символов; сброс по e-mail; опционально вход по magic link.
- [ ] Шифрование токенов интеграций (pgsodium / AES-GCM с ключом из env).
- [ ] Аудит-лог: кто удалил/экспортировал/изменил документ.

## Документы для клиентов (польский)

- `Regulamin` сервиса;
- `Polityka prywatności` сервиса;
- `Umowa powierzenia przetwarzania danych (DPA)` — принимается при регистрации галочкой;
- список субпроцессоров (Supabase, Google Cloud, Resend, Telegram, Stripe, Postmark, Anthropic — если включён ИИ).

Эти тексты — черновики, перед продажей проверить у юриста.

## Права субъектов данных

- экспорт всех данных фирмы (CSV + ZIP документов) — в «Ustawienia»;
- удаление лида по просьбе клиента (окончательно, включая файлы документов);
- удаление аккаунта фирмы: данные стираются через 30 дней.

## ИИ и данные

Отправка текста договора/письма в Claude API — только если фирма включила ИИ-помощника в настройках (по умолчанию для разбора договора спрашиваем при загрузке). Модели не обучаются на данных API — указать в политике.
