# 03 — План работ (roadmap)

**Это главный трекер прогресса.** Агент берёт первую невыполненную задачу `[ ]` сверху вниз, делает, ставит `[x]` и пишет запись в `PROGRESS.md`. Задачи маленькие: одна задача ≈ одна сессия ≈ один коммит.

Оценки — для работы по вечерам с ИИ-агентом.
