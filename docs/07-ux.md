# 07 — Интерфейс и удобство

## Принципы

1. **Mobile-first.** Владелец отвечает на лиды с телефона, часто на мероприятии. Каждый экран сначала проектируется под 390 px.
2. **3 нажатия до оферты.** Лид → «Wyślij ofertę» → выбрать пакет/стиль → «Wyślij». То же для договора.
3. **Никаких пустых экранов.** Пустое состояние всегда объясняет, что сделать дальше, и даёт кнопку.
4. **Предпросмотр перед любым внешним действием** (письмо, SMS, оферта клиенту). Отправка только по явной кнопке.
5. **Отмена вместо «Вы уверены?»** — где можно, действие выполняется сразу и показывается тост «Cofnij» на 8 секунд.
6. **Польский язык, простые слова.** Не «pipeline», а «Etapy». Не «lead source», а «Skąd przyszedł».
7. Скорость: интерфейс реагирует мгновенно (оптимистичные обновления), списки с Realtime — новый лид появляется без перезагрузки.

## Навигация

- Телефон: нижняя панель — Dzisiaj · Leady · **＋** (новый лид) · Kalendarz · Więcej.
- Компьютер: боковая панель слева, быстрый поиск `⌘K`.

## Визуальный стиль — «Sezon» (решение 011)

- Тёмная тема. Токены — только в `app/globals.css` (`bg`, `surface`, `surface-2`, `line`, `line-strong`, `ink`, `ink-soft`, `ink-faint`, `urgent`, `hold`, `ok`, `brand`).
- Заголовки и крупные цифры — `font-display` (Clash Display), текст — Satoshi.
- Красный (`urgent`) — только для проданных дат и срочного (лид ждёт > 10 минут, ошибки). Янтарный (`hold`) — предварительная бронь. Зелёный (`ok`) — «готово/свободно».
- Ключевые компоненты: `components/season/season-strip.tsx` (сезон суббот), `components/leads/lead-ticket.tsx` (бон лида с таймером), `components/app-shell/page.tsx` (PageHeader, Stat, Card, EmptyState).
- Скругления: карточки 22px, кнопки и поля 10px, боны 14px сверху + зубчики снизу. Без теней — разделение цветом поверхности и линиями.
- Кнопки не меньше 44 px по высоте на телефоне. Контраст WCAG AA.

## Этапы по умолчанию (пресет «event services»)

`Nowy` → `Skontaktowano` → `Oferta wysłana` → `Oferta zaakceptowana` → `Umowa wysłana` → `Zadatek wpłacony` (won) · `Odrzucony` (lost) · `Spam` (lost).
Пресет можно редактировать в «Ustawienia → Etapy».

## Перенос удачных решений из Telegram-бота v39

- карточка с компактными кнопками и «⋯ Więcej» → в вебе меню «⋯» на карточке;
- правка лида одной формой + откат → редактирование по месту + «Cofnij»;
- follow-up с предпросмотром и правкой текста перед отправкой;
- история документов (последние версии);
- меню для гостей (PDF + Word) — как тип документа для пресета «mobilny bar».

### Реализовано: Leady (1.4)
Список с поиском, фильтрами этапа/канала/дат/сотрудника и страницами по 50. На телефоне дополнительные фильтры раскрываются кнопкой «Filtry». Realtime обновляет серверные данные с сохранением фильтров; при отсутствии соединения доступна «Odśwież». Ошибки загрузки объясняются по-польски, есть повтор. Проверка авторизации остаётся в DAL и RLS.

### Карточка (1.5)
Правка каждого поля по кнопке «Edytuj», этап меняется сразу; «Skontaktowano» отмечает первый ответ. «Cofnij» доступна 8 секунд и не перетирает новые изменения коллеги. Бюджет вводится в zł, сохраняется в грошах. Заметки и подсказка дубликата — в истории (последние 200 событий). Телефон/WhatsApp/e-mail открывают выбранный канал; документы честно отключены до этапа 2.

### Канбан (1.6)
Переключатель Lista/Etapy сохраняет фильтры. В канбане отображаются те же 50 лидов текущей страницы (показано явное количество); колонки листаются вбок. Drag & drop за ручку (dnd-kit/core), на телефоне/клавиатуре доступно поле «Zmień etap». Перенос оптимистичный, сохранение/история/отмена используют операции 1.5.

### Dzisiaj с данными (1.12)
Боны и счётчик меню берутся из Supabase. Таймер — от серверного времени с монотонным отсчётом, обновление каждые 15 секунд и при возврате на вкладку. «Skontaktowano» убирает бон из очереди; «Cofnij» его возвращает. Субботы с неотклонённым лидом — inquiry; настоящие hold/booked добавит 3.6. «Ten miesiąc» показывает новые и выигранные запросы и незавершённые follow-up; конверсия документов остаётся «—» до этапа 2.
